AI CONTENT FACTORY — DOMAIN CONTRACT

Domain defines business meaning for Project, Series, Episode, Character, World, Location, Scene, Shot, Dialogue, Asset and Job.

RULES
- Domain is independent of Android UI and infrastructure.
- No Room annotations/entities, Retrofit, SQL or provider SDKs.
- IDs are stable opaque identifiers.
- Timestamps use one canonical instant representation.
- State transitions are explicit and validated.
- Scene order is unique within an episode; shot order is unique within a scene.
- Cross-project references are forbidden.
- Job dependencies form a DAG; cycles are invalid.
- Domain schema changes require migration and compatibility review.

CORE GRAPH
Project→Series→Episode→Scene→Shot.
Series→Characters/World/Locations.
Scene→Dialogue/Shots.
Shot→Jobs/Assets.

ACCEPTANCE
[ ] Infrastructure-free [ ] Invariants tested [ ] Stable IDs [ ] Explicit states [ ] Project isolation [ ] Migration tests
