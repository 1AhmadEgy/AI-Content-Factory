AI CONTENT FACTORY — ERROR CONTRACT

ERROR CATEGORIES
VALIDATION, NETWORK, PERSISTENCE, PROVIDER, WORKER, QC, LICENSE, HARDWARE, AUTHENTICATION, AUTHORIZATION, CONFLICT, TIMEOUT, CANCELLATION, DEPENDENCY, RESOURCE, CONFIGURATION, UNKNOWN.

ERROR STRUCTURE
category, code, message, retryable, details, internal cause/context.

RULES
- Codes are uppercase stable identifiers such as NETWORK_TIMEOUT, PROVIDER_UNAVAILABLE, QC_INVALID_VIDEO.
- Messages are never parsed for control flow.
- Retryability is explicit: RETRYABLE, NON_RETRYABLE or CONDITIONAL.
- UNKNOWN is last-resort only.
- Cancellation is distinct from failure.
- Dependency failure preserves the original cause.
- License UNKNOWN is never treated as VERIFIED.
- HTTP status is transport metadata, not the application error identity.
- API/event serialization excludes Throwable, secrets and sensitive diagnostics.
- Error context should correlate requestId, traceId, jobId and executionId.
