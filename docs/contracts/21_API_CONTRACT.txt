AI CONTENT FACTORY — API CONTRACT

BASE PATH
/api/v1

RULES
- API exposes application/domain DTOs, never Room/SQL/provider SDK types.
- AI generation requests are asynchronous and normally return 202 Accepted.
- Bearer authentication is required for protected resources.
- Authorization is project-scoped.
- Idempotency-Key is required for mutation endpoints where duplicate requests could create jobs/assets.
- Pagination, sorting and filtering are explicit.
- Errors use canonical error codes.
- Asset files are accessed through authorized endpoints, never unrestricted filesystem paths.
