AI CONTENT FACTORY — RESULT CONTRACT

Result is the canonical operation outcome shared across domain, application, data, infrastructure, workers and API boundaries.

CONTRACT
sealed interface Result<out T> { data class Success<T>(val data:T):Result<T>; data class Failure(val error:AppError):Result<Nothing> }

RULES
- Success means the operation produced its contractually valid result.
- Failure always contains AppError.
- Null, false, empty strings and arbitrary exceptions are not failure substitutes.
- Exceptions are normalized at architectural boundaries.
- Error codes are machine contracts; messages are not.
- retryable is explicit and does not itself trigger retry.
- Async request Success means request/job creation succeeded, not generation completion.
- Generation completion requires output persistence, verification, provenance and required QC.
- Secrets and stack traces must not cross external boundaries.
- Result and GenerationJob status are different concepts.

ACCEPTANCE
