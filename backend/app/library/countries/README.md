# Independent Country Libraries

Each country owns an independent library identified by a stable `libraryId`.

A country may start as `catalog-only`; this means its metadata and supported
languages exist, but no claim is made that local characters/locations/content
have been seeded yet.

When a country is expanded, populate the library contract with:

- characters and reusable character identities
- locations, landmarks and cities
- environments, architecture and clothing
- dialects and speech styles
- customs and behavior rules
- vehicles, transport and workplaces
- fictional/general archetypes
- comedy, action, drama, mystery, adventure and family templates
- relationships, continuity, story facts and open threads
- props, visual rules and audio rules

Never copy one country's mutable records into another country's library. Shared
technical schemas are allowed; content identity remains country-scoped.
