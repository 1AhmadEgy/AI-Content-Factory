# افهم واضحك — Brand Kit

## Core identity
- Name: **افهم واضحك**
- Tagline: **وخد المفيد.**
- Intro voice: **افهم واضحك… وخد المفيد**
- Format: vertical short-form, 1080×1920

## Palette
- Background: `#0B1020`
- Primary yellow: `#FFC928`
- Accent orange: `#FF7A3D`
- Text: `#FFFFFF`

## Motion language
1. 0–600 ms: logo/icon pop-in.
2. 600–1500 ms: «افهم» appears with a small upward motion.
3. 1500–2200 ms: «واضحك» snaps in with the orange accent.
4. 2200–2400 ms: tagline settles: «وخد المفيد.»

## Outro
- Duration: 1.8 s
- Main line: «افهم واضحك»
- Secondary line: «وخد المفيد.»
- Optional CTA: «تابع للمزيد»

## Shorts template
- Safe area: keep important text inside the central 80% width and 82% height.
- Watermark: bottom-right, 82% opacity by default.
- Captions: white text, bold weight, yellow emphasis for key words.
- Avoid covering faces or platform UI zones.
